📦 APK 构建指南

本指南将帮助您将经典怀旧游戏打包成 Android APK 文件。

🚀 方法一：PWA 安装（最简单）推荐

无需构建，直接安装到手机

将 app 文件夹部署到任意 Web 服务器（如 GitHub Pages、Netlify、Vercel）
在手机 Chrome 浏览器中打开网址
点击地址栏右侧的 安装 图标（或菜单中的"添加到主屏幕"）
应用将添加到主屏幕，支持全屏横屏运行
💡 提示：PWA 安装后可以离线使用，体验接近原生 APP。

🔧 方法二：使用 Capacitor 构建 需要 Android Studio

生成真正的 APK 文件

安装 Node.js（16.x 或更高版本）
安装 Android Studio
运行构建脚本：
.\build-capacitor.ps1
用 Android Studio 打开 fc-mobile\android 目录
等待 Gradle 同步完成
点击菜单 Build → Build Bundle(s) / APK(s) → Build APK(s)
APK 生成在：fc-mobile\android\app\build\outputs\apk\debug\

⚙️ 方法三：使用 Cordova 构建

传统混合应用方案

安装依赖：
npm install -g cordova
运行构建脚本：
.\build-apk.ps1
进入项目目录：
cd fc-mobile
添加 Android 平台：
cordova platform add android
构建 APK：
cordova build android

📱 方法四：使用在线打包服务

无需本地环境

访问在线打包网站，如：
• GoNative.io
• WebIntoApp.com
• AppsGeyser.com
上传 app 文件夹或输入网址
配置应用信息（名称、图标等）
下载生成的 APK 文件

❓ 常见问题

⚠️ 横屏设置：已在配置中设置为横屏模式。如果仍然显示竖屏，请检查手机的自动旋转设置。
⚠️ 全屏显示：应用配置为全屏模式。首次运行可能需要授予权限。
💡 游戏兼容性：所有游戏均使用 JSNES 模拟器运行，兼容绝大多数 FC/NES 游戏。
